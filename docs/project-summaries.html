uSport.ai

Knowledge graph · Agents · RAG2023 – present

AI recruiting platform matching student-athletes to NCAA coaches. Ten product surfaces over one substrate: a Neo4j graph of 8M+ athletes, 51K coaches, 176K schools, 15M+ swim results and 1,400+ NCAA rules, with seven vector indexes native to the same database.

ModelsClaude (all agents), GPT-4o (re-ranking, scoring, email), text-embedding-3-small (1536-d). Task models documented separately below.
TrainingNo model trained at platform level — retrieval and agent behavior are grounded by Cypher traversals and vector search over indexed content.
EvaluationPer-subsystem (see Two-Tower Retrieval and Career Projection). Agent quality measured through Agent Gym's judge rubric.
ResultsIn production. 27.9M-node graph, 8.4M athlete profiles, 7 vector indexes, 15+ agent tools across 6 RAG chains.

Agent Gym

Multi-agent simulation2026

Simulation environment where a coach agent and an athlete agent negotiate across three structured phases against real profiles from the graph. A separate model scores every turn; high-scoring episodes become retrieval context for the production assistant.

ModelsAgents: Claude Sonnet 4.5. Judge: GPT-5 (forced for auto-training) or Claude. Embeddings: text-embedding-3-small.
TrainingNo gradient updates. Improvement is in-context: episodes scoring ≥ 0.6 total reward and ending in a successful terminal state are retrieved as few-shot examples for later episodes and for the live assistant. Cloud Scheduler generates 1 episode/hour unattended.
EvaluationCross-model LLM judge, phase-aware, four weighted dimensions per turn — offer-probability delta 50%, factual grounding 20%, regulatory compliance 20%, sentiment 10%. Solo-research mode uses a separate 35/25/20/20 rubric.
Results3 episode modes in production; episodes stored as graph nodes with 1536-d embeddings and consumed by the shipped recruiting assistant.

Two-Tower Retrieval

NLP · Dense retrieval2026

Bidirectional coach–athlete matching for college swimming recruiting. UC Berkeley DATASCI 266 (NLP with Deep Learning). Tests whether decoder-LLM normalization of inputs beats contrastive fine-tuning.

ModelBAAI/bge-large-en-v1.5 (1024-d, 512 tokens), shared by both towers. Plus T5-small for match explanations.
TrainingContrastive fine-tuning, MultipleNegativesRankingLoss, 3 epochs, 1,196 triplets. Hard negatives = coaches at schools swimming the same events where the athlete is not competitive. Ground truth from 22,974 benchmark-derived pairs.
Evaluation70/30 split by swimmer (511 train / 220 test, disjoint — no leakage). P@K, MRR, nDCG@10, plus negative-pair AUC-ROC and bootstrap CIs.
ResultsForward MRR 0.304 → 0.883 from fine-tuning (2.9×); LLM-normalization treatment 0.909 but with overlapping CIs — fine-tuning is the effect, normalization is not. Top-1 hit rate 83.6%. Reverse direction 0.045 → 0.202 (4.5× and still weak — coach profiles carry little distinctive text). Negative separation 0.015 → 0.086, AUC 0.633 → 0.666. T5 explanations: ROUGE ≈ 0.53 on n=2 — illustrative only.

Career Projection

Applied ML · Sports analytics2026

Predicts whether a high-school athlete reaches a D1 roster or a professional league, across eight sports. Built so a coach reading a percentage can also read how much to trust it.

ModelsLogistic regression and gradient-boosting classifiers in a scikit-learn Pipeline(median impute → scale → classifier); a GradientBoostingRegressor for NBA career length. ~20 models over 8 sports.
TrainingPer-sport pipelines: scrape → ETL into Neo4j → features → train → export. Features shared between trainer and scorer via one module so they cannot drift. Leakage controls: recruiting overlays sourced before the prediction moment; games-played and era-asymmetric stats explicitly excluded and recorded in the metrics JSON.
Evaluation5-fold stratified CV and forward-in-time temporal holdout (train on class ≤ cutoff, test on later classes), plus 10-bucket out-of-fold Expected Calibration Error and top-N hit tables.
ResultsLacrosse HS→D1: CV 0.653 → temporal 0.609. HS→Pro men: CV 0.869 → temporal 0.706 (−16.3 pp; the temporal number is what the product displays). Calibration: HS→Pro men ECE 0.6 pp after removing class balancing (was 24 pp). Top-200 precision 99.5% at a 60.8% base rate (1.64× lift). Basketball HS→NBA GBM CV-AUC 0.79; NBA longevity MAE 3.63 yrs vs 3.85 baseline, R² 0.077.

OmniSearch

Multi-agent reinforcement learning2026

Simulation platform for testing coordinated drone and ground-robot swarms in wildfire search-and-rescue. UC Berkeley MIDS capstone.

ModelsHAPPO (heterogeneous-agent PPO, via HARL) as the primary policy; MAPPO and IPPO as controlled comparisons. Perception: YOLOv8s detectors plus a probabilistic detection model during RL.
TrainingVMAS wildfire scenario on real USGS/OpenStreetMap terrain, physical units, γ = 0.99, 900 steps @ 2 s = 30 min simulated per episode. 4 UAVs, 3 UGVs, 5–10 survivors on 1 km². BC warm-start and DAgger imitation available. Detectors fine-tuned on synthetic composites.
Evaluation100 held-out seeds per configuration against six scripted baselines (lawnmower, ant-colony, highest-confidence, random walk). Communication-dropout sweep 0–100%. Detectors evaluated against real datasets, not their own validation split.
ResultsMission success 80% vs 72% (ant-colony) and 68% (lawnmower). Survivor confirmation ~10% faster. Under communication dropout the learned policy holds 76–82% through 70% loss while baselines fall ~14 points immediately. Detection: HERIDAL aerial 0.86 recall @ 0.50 precision; HIT-UAV thermal mAP50 0.923 real-trained vs 0.167 synthetic-only.

Jailbreak Detection

AI safety · Multimodal ML2026

Predicts whether a multimodal prompt will break an LLM's safety guardrails before any content is generated, and which policy it would violate. UC Berkeley DATASCI 207.

ModelsBaseline multinomial logistic regression; random forest; and a two-branch DNN (TensorFlow) — text+image TF-IDF → 256 → 128 ReLU with dropout → 128-d embedding, fused with a 16-d harm-score branch → 144-d → 64 → 17-way softmax.
Training48,000 prompts (JailBreakV-28K + 20K benign), 80/10/10 stratified. 26-d pre-generation feature vector: prompt length, roleplay and instruction-override markers, Detoxify harm score, OCR text, LLM image descriptions, FigStep flag. Dropout 0.3, early stopping patience 5, Adam, LR tuned 1e-4 vs 1e-5.
EvaluationMacro-average recall (false negatives are the risk), 5-fold stratified CV, per-category confusion matrices. Labels derived by a rule-based refusal classifier validated at 96% human agreement on 100 samples.
ResultsRecall 69.4% → 93.0%, accuracy 98.5%. Notably, adding image features to the linear model moved recall only 69.4 → 69.6, and random forest to 70.2 — multimodal features paid off only once the architecture could fuse them. Benign: 1.00 recall and precision. Malware and Financial Fraud > 0.97 F1. Long tail fails: Child Abuse 0.42 recall (12 training samples), Health misses 30% (10 samples).

DevDigest

Developer tools · Applied LLM2026

Local-first AI pull-request reviewer whose engine cannot cite a line that is not in the diff. Also a course template: a minimal working starter plus eight lessons that each add one feature back.

ModelsProvider-injected LLM — Anthropic, OpenAI, or OpenRouter. No model trained.
TrainingNot applicable. Quality comes from retrieval and constraint: a repo-intel index (ast-grep symbols, dependency-cruiser import graph, PageRank + git hotness) supplies a repo map as prompt context, computed once on clone.
EvaluationA mandatory grounding gate: every finding is checked mechanically against the diff and dropped if it cites no real changed line; the verdict score is recomputed from survivors rather than trusted from the model. 73 test files across five suites — hermetic units with a stubbed provider, testcontainers Postgres integration, deterministic browser e2e — each with its own CI workflow.
ResultsWorking end to end: 36K lines of TypeScript across five packages. Untrusted diffs are fenced with an injection guard; structured output validated via Zod-derived JSON Schema with parse-and-repair.

Onpace

Mobile · Applied LLM2026

Swim-coaching iOS app (App Store, v1.0.4). Every generative surface is bounded so the model proposes and the coach disposes.

ModelsClaude Sonnet for plan generation, in a callable Cloud Function. Retrieval: Neo4j swim knowledge graph + vector search with text-embedding-3-small (1536-d). No model trained.
TrainingNot applicable. Hybrid graph + vector RAG. Anti-repetition: a rolling per-athlete history feeds the 4 most recent generated sessions back into the prompt (3 persisted forward) so plans progress instead of looping.
EvaluationNo formal offline evaluation. Safety is enforced structurally — AI plans arrive as drafts into a coach's editor, adjustment can only modify an existing coach workout (preserving focus and authorship, dropping paddles on reported shoulder pain), and video review structures the coach's own narration rather than grading the swimmer.
ResultsShipped to the App Store. Swimmer-reported outcomes from reviews: 100 m pace 1:45 → 1:38 in six weeks; one beginner from not completing a length to 400 m continuous.
